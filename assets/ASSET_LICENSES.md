# Asset sources and licenses

Everything under `assets/` comes from [tourzhao/Tanks3D](https://github.com/tourzhao/Tanks3D)
(commit `a24ab9e`). The game's code is unaffected; each file keeps its own upstream terms.

## Audio — `assets/audio/`

The `.ogg` files are byte-for-byte copies of Tanks3D's `resources/sounds/`. Each `.m4a` is an
AAC (96 kbps) transcode of the matching `.ogg`, for browsers without Ogg Vorbis; the game
picks one per browser.

- **20 effect sounds** (cannon, impacts, pickups, engine idle/moving, respawn, pause, menu,
  score tally, explosions): from
  [`krystiankaluzny/Tanks@f59aea3`](https://github.com/krystiankaluzny/Tanks/tree/f59aea31638117e20bc03276026bdbb9f8828b47/resources/sounds),
  credited to Redas Jefisovas (`holoflash`). MIT — see `licenses/MIT-krystiankaluzny-Tanks.txt`.
- **`stage_start_up.ogg`, `game_over.ogg`** (the Battle City stage-start and game-over jingles):
  from [`JustoSenka/BattleCity@3a07004`](https://github.com/JustoSenka/BattleCity/tree/3a07004ba8e53baea74ff70d2ecc22b017eb9b20/Assets/Audio),
  which declares MIT — see `licenses/MIT-JustoSenka-BattleCity.txt`. As Tanks3D notes, that
  declaration is not independent confirmation of rights in Namco's original *Battle City*
  music.

## Textures — `assets/textures/`

`battlefield_grass.jpg` and `urban_masonry.jpg` are 512×512 JPEG downscales of Tanks3D's
`resources/textures/*.png` (generated by the Tanks3D project). They are offered under the
PolyForm Noncommercial License 1.0.0 —
<https://polyformproject.org/licenses/noncommercial/1.0.0>, full text in
`licenses/PolyForm-Noncommercial-1.0.0-Tanks3D.md` — so they may only be used for
noncommercial purposes.

## Techniques, not code

The tank surfaces (polygon camouflage, painted/metal/rubber material split, two-tone gun
tubes), lighting angles, directional muzzle jet, shell tracer shape and explosion/smoke
timing are reimplemented in Three.js from Tanks3D's published art notes and parameters. No
Tanks3D source code is included.
